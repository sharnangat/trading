# Indian Stock Scanner

This repository contains a Python script that scans selected Indian NSE stocks using moving averages and RSI.

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python indian_stock_scanner.py
```

## What it checks

- 20-day SMA vs 50-day SMA
- RSI (14)
- 20-day average volume
- 52-week high
- Bullish breakout-style conditions

This is a simple screening script for research and education, not financial advice.
